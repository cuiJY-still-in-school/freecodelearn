# PersonalAC 1.3 版本核心修改内容清单

本文档聚焦于 1.3 版本的云端化转型、登录制度引入及极致迁移能力的实现。

---

## 1. 登录制度与多端同步 (Auth & Sync)

**目标：** 通过极简登录实现跨设备配置同步与云端数据隔离。

- [ ] **引入极简登录 (Sync-Auth)**：
    - 新增登录页面：支持用户名 + 唯一 Sync Token 登录。
    - **逻辑变更**：系统不再是“本地孤岛”，登录后自动从云端数据库拉取个人配置。
- [ ] **配置全面云端化**：
    - 将 `settings.json` 等本地配置文件迁移至 SQLite `Settings` 表。
    - 包含：AI 模型偏好、Email API 授权码、Bot 绑定信息。
    - **效果**：在任何设备登录网页，所有设置自动就绪，无需二次配置。

---

## 2. 云端智能存储 (Smart Cloud Workspace)

**目标：** 在服务器上实现全自动的文件管理与检索。

- [ ] **Agent 自动化归档 (Auto-Organizer)**：
    - Agent 获得文件系统的“管家权限”。
    - **逻辑**：每当有新文件（Email 附件或 Web 上传）进入，Agent 自动解析内容，按 `年份/月份/分类/` 重新命名并移动文件。
- [ ] **轻量化全文本检索 (SQLite FTS5)**：
    - 启用 SQLite 的 FTS5 扩展。
    - **逻辑**：Agent 在存储文件时自动提取文本索引存入 FTS 表。
    - **效果**：在低配服务器上也能实现秒级的文档内容关键字搜索。

---

## 3. 快速迁移与备份 (Instant Migration)

**目标：** 实现环境与数据的秒级迁移。

- [ ] **一键快照功能 (System Snapshot)**：
    - 新增 `Export/Import` 接口。
    - **逻辑**：将 SQLite 数据库与 Workspace 核心目录打包为单一 `.pac` 压缩包。
    - **效果**：当您需要更换服务器时，只需在旧服务器导出、新服务器导入，瞬间恢复所有数据。
- [ ] **环境适配逻辑**：
    - 增加路径自适应代码，确保 Workspace 目录在不同操作系统的路径下均能正常映射。

---

## 4. 轻量化 Web 部署 (Server-Side Optimization)

**目标：** 优化资源占用，适配低配置服务器。

- [ ] **废弃 Electron，转向 Web 服务**：
    - 前端转为 React/Vue 静态部署。
    - 后端转为轻量级 Node.js/Python 服务。
- [ ] **事件驱动唤醒 (Event-Driven)**：
    - Agent 核心逻辑不再常驻内存。
    - **触发机制**：仅在收到新邮件或用户 Web 操作时唤醒处理任务，处理完后自动进入低功耗休眠，确保不占用服务器 CPU。

---

**执行建议：** 1.3 版本的关键在于**数据库结构的云端化重构**。建议先完成登录与配置上云，确保多端同步走通，再逐步实现 Agent 的自动化归档逻辑。
