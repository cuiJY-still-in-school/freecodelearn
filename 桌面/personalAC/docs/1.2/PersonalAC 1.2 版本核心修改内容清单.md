# PersonalAC 1.2 版本核心修改内容清单

本文档列出 1.2 版本中针对系统简化、权限松绑及 Agent 编排优化的核心修改点。

---

## 1. 系统架构简化：彻底“去中心化”

**目标：** 移除所有阻碍个人使用的门槛，实现开箱即用的最高权限。

- [ ] **移除登录/认证系统**：
    - 彻底删除前端登录页面 (Login Page) 及相关的路由守卫。
    - 移除后端/本地数据库中的用户密码校验、Token 管理逻辑。
    - **默认权限**：系统启动后，默认以 `SuperAdmin` (最高管理者) 身份进入，跳过所有身份选择。
- [ ] **解除存储配额限制**：
    - 删除 1.1 版本中的 10GB 硬性空间检查代码。
    - 策略调整为：仅监控物理磁盘剩余空间，当剩余空间低于安全阈值（如 500MB）时发出警告，不再做人为配额限制。

---

## 2. Agent 编排优化：从“问答”到“反馈升维”

**目标：** 丰富 Agent 的输出手段，使其具备更强的主动性和可视化能力。

- [ ] **可视化反馈增强 (Visual Feedback)**：
    - **Mermaid 渲染引擎集成**：Agent 在解释复杂逻辑、知识结构或历史事件时，必须主动生成 Mermaid 代码并由前端渲染成思维导图或流程图。
    - **知识卡片系统**：Agent 可生成 JSON 格式的知识卡片，前端将其渲染为高颜值的 UI 组件（包含重点、公式、例题）。
- [ ] **主动式任务处理 (Proactive Action)**：
    - **变动感知触发**：当 Email API 接收到新资源或 Workspace 文件更新时，Agent 自动启动“后台预解析”，并主动推送一份《资源简报》。
    - **学习进度闭环**：Agent 根据近期的聊天记录和资源变动，主动生成“每日回顾”或“薄弱点测验”，而无需用户手动请求。
- [ ] **交互式实验环境 (Sandbox Feedback)**：
    - **代码/公式即时运行**：当涉及编程或数学问题时，Agent 可以在 Workspace 中创建临时的运行环境，并将运行结果（或 LaTeX 渲染图）反馈给用户。

---

## 3. 核心逻辑变更清单 (Code-Level)

- [ ] **Agent 决策树升级**：
    - 新增 `Action: Generate_Diagram` 决策分支。
    - 新增 `Action: Proactive_Report` 决策分支。
- [ ] **UI 组件库扩充**：
    - 引入 `mermaid.js` 库。
    - 新增 `Markdown-Extra` 支持，用于更好地渲染数学公式 (KaTeX) 和代码块。
- [ ] **数据库变更**：
    - 移除 `User` 表中的 `password_hash` 等敏感字段。
    - 增加 `AgentTask` 表，用于记录 Agent 主动发起的后台任务状态。

---

**执行建议：** 1.2 版本的重点在于“减法”（删登录、删配额）和“加法”（加可视化、加主动反馈）。建议先完成减法部分以简化代码结构，再集中精力优化 Agent 的 Prompt 和决策逻辑。
