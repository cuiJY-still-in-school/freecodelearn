## 1. 快速开始

### PersonalAC 是什么

PersonalAC 是一个专为学生和家长设计的个人学习 AI 助手。它不只是一个聊天机器人——它会记住你学过什么、哪里薄弱、什么时候该复习，并且会主动在后台帮你安排学习任务。家长可以上传试卷和成绩，AI 会自动分析并更新学生的知识点掌握情况。

### 版本说明

PersonalAC 有两个版本，本指南主要介绍 **v1.3 服务器版**。服务器版运行在 Node.js 上，通过浏览器访问，支持家庭多设备共享使用。

如果你用的是**本地版**（通过 `npm install -g personalac` 安装），请直接跳到[启动](#启动)部分，本地版开箱即用，默认端口是 7575。

### 安装

需要提前安装 Node.js 20 或更高版本。

**本地版（个人使用，推荐新手）：**

```bash
cd codescore/local
npm install
npm link
```

安装完成后，在任意位置都可以直接运行 `personalac` 命令。

**服务器版（家庭共用、多设备）：**

```bash
cd codescore/1.3/server
npm install

cd ../frontend
npm install
npm run build
```

### 启动

**本地版：**

```bash
personalac                  # 默认端口 7575，自动打开浏览器
personalac --port 8080      # 自定义端口
personalac --no-open        # 启动但不自动打开浏览器
```

**服务器版：**

```bash
cd codescore/1.3/server
npm start                   # 默认端口 3000
```

启动成功后，终端会显示类似这样的内容：

```
====================================
  PersonalAC v1.3
  http://localhost:3000
  Sync Token: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
====================================
```

这行 **Sync Token** 是你第一次登录用的凭证，请先记下来（或者直接截图保存）。

### 打开界面

在浏览器中访问 `http://localhost:3000`（服务器版）或 `http://localhost:7575`（本地版），然后输入终端显示的 Sync Token，登录即可。

## 2. 首次配置（监护人）

第一次登录建议由家长完成初始配置，之后学生才能正常使用。

### 第一步：输入 Sync Token 登录

打开浏览器，访问服务地址，在登录框中输入终端显示的 Sync Token，点击登录。

### 第二步：填写监护人信息

第一次登录会出现设置向导，填入你的名字（例如：李妈妈）。这个名字会在 AI 日志和报告中用来区分操作来源。

### 第三步：创建学生账户

在向导中创建学生账号，需要填写：

- 学生姓名（例如：小明）
- 年级（例如：高二）
- 主要学习科目（例如：数学、物理、英语）

创建完成后，系统会生成学生专属的 **Sync Token**。这个 Token 就是学生的登录凭证，请妥善保存，或者直接告诉学生。

### 第四步：配置 AI

点击右上角进入**设置** → **AI** 选项卡。

填写以下信息：

- **API Key**：你的 AI 服务密钥（见[第 5 节](#5-ai-配置详解)了解各平台如何获取）
- **模型**：从下拉列表中选择（推荐 Claude 或 GPT-4o）
- 如果使用非官方接口，还需要填写 **Base URL**

填完点击保存，然后可以发一条测试消息确认 AI 能正常回复。

### 第五步：设置学习目标

点击**设置** → **学习目标** 选项卡，填写：

- 备考类型（例如：高考、中考）
- 目标考试日期
- 当前学校进度（例如：本学期已学到第几章）

这些信息会让 AI 在每次对话前都知道距离考试还有多少天，从而给出更有针对性的学习建议。

## 3. 学生使用

### 登录

学生用自己的 Sync Token 在同一个地址登录。登录后看到的是**学生专属界面**，只显示聊天功能，没有配置和管理选项，界面更简洁。

### 开始聊天

直接在输入框里提问就好。AI 会在第一条消息中主动告诉你今天的学习状态，比如：

> "你好小明！距离高考还有 87 天。你有 3 个知识点超过 7 天没复习了，记忆可能有些模糊了——要不要先来看看？另外上次物理的圆周运动你说还不太懂，今天要继续吗？"

### 聊天功能

| 操作 | 方式 |
|---|---|
| 发送消息 | 回车键 或 点击发送按钮 |
| 换行（不发送） | Shift + Enter |
| 上传图片 | 点击图片按钮，或直接粘贴截图 |
| 停止 AI 回复 | 点击停止按钮 |

AI 的回复支持完整的 Markdown 格式，公式、代码块、列表都能正常显示。

### 上传试卷

把试卷拍照或截图，直接粘贴到聊天框里发送，然后告诉 AI "这是我刚考的试，帮我分析一下"。AI 会识别题目、分析错误，并自动更新对应知识点的掌握记录。

### 学习建议

你可以直接问 AI：

- "今天该复习什么？"
- "我数学最薄弱的地方是什么？"
- "出几道题考考我"
- "刚才学的内容帮我记录一下"

AI 不会只是嘴上说说，它会真正把结果写入数据库，下次对话时还记得。

## 4. 监护人功能

监护人登录后拥有完整功能，包括聊天、仪表盘、配置、Agent 日志等。

### 上传成绩和资料

直接在聊天窗口上传图片（成绩单、试卷、错题截图），告诉 AI 这是学生的成绩数据。监护人上传的内容会以**最高可信度**写入学生的知识点记录，和学生自己说"我学会了"相比，系统更信任监护人上传的客观数据。

### 查看 Agent 日志

进入**Agent 日志**页面，可以看到 AI 在后台自动执行了哪些任务，比如：

- 今日学习回顾
- 薄弱点自动测验
- 邮件附件解析记录

每条日志都显示执行时间、任务类型和结果，方便了解 AI 在做什么。

### 设置勿扰时间

如果不希望 AI 在某些时段发起主动提醒，可以在设置中配置**勿扰时段**（填写开始和结束时间，格式 HH:MM）。勿扰时段内 Agent 不会触发主动任务。

## 5. AI 配置详解

### 支持的 AI 服务

PersonalAC 支持主流 AI 服务，以及任何兼容 OpenAI 接口的第三方服务。

**Anthropic（Claude 系列）**

| 模型 | 适合场景 |
|---|---|
| claude-3-5-sonnet | 综合能力强，速度快，日常首选 |
| claude-3-5-haiku | 轻量快速，适合简单问答 |
| claude-3-7-sonnet（thinking 版） | 深度推理，适合难题分析 |

获取 API Key：访问 https://console.anthropic.com

**OpenAI（GPT 系列）**

| 模型 | 适合场景 |
|---|---|
| gpt-4o | 强大，支持图片上传 |
| gpt-4o-mini | 便宜快速 |
| o1 / o3-mini | 数理推理模型 |
| o4-* | 最新推理模型 |

获取 API Key：访问 https://platform.openai.com

**其他 OpenAI 兼容接口**

只要是兼容 OpenAI 协议的接口，都可以使用，填写自定义 Base URL 即可。常见例子：

- DeepSeek：`https://api.deepseek.com/v1`，Model ID `deepseek-chat`
- Moonshot（Kimi）：`https://api.moonshot.cn/v1`
- 本地 Ollama：`http://localhost:11434/v1`

**models.dev 格式**

模型 ID 支持 `provider/model` 的简写格式，例如 `anthropic/claude-3-5-sonnet`，系统会自动解析。

### 推理模型的特殊说明

模型名称中含有 `o1`、`o3`、`o4-`，或 Claude 的 `-thinking` 后缀，系统会自动识别为**推理模型**，并开启扩展思考模式。这类模型回复速度较慢，但对复杂数理题效果更好。

### 如何配置

进入**设置** → **AI** 选项卡，填写：

1. **提供商**：从下拉列表选择，或选"自定义"
2. **API Key**：粘贴你的密钥
3. **Base URL**（可选）：使用第三方或本地服务时填写
4. **模型 ID**：选择或手动输入

点击保存后，可以发一条消息测试是否正常。

## 6. 邮件集成

### 这个功能有什么用

你可以把试卷、学习资料、成绩单等以**邮件附件**的形式发送到配置的邮箱，PersonalAC 会自动收取邮件、解析附件，并将内容归档为学习资源。这样家长在外面拍到试卷，直接发邮件，回家前资料就已经导入系统了。

### 配置步骤

进入**设置** → **邮件** 选项卡，填写以下信息：

- **IMAP 服务器地址**
- **邮箱账号**
- **授权码**（注意：不是邮箱登录密码，是专用授权码）
- **端口号**（通常 993）

### 常用邮箱配置参考

| 邮箱 | IMAP 服务器 | 端口 | 说明 |
|---|---|---|---|
| QQ 邮箱 | imap.qq.com | 993 | 需在 QQ 邮箱设置中开启 IMAP，生成授权码 |
| 163 邮箱 | imap.163.com | 993 | 需开启 IMAP，使用授权码 |
| Gmail | imap.gmail.com | 993 | 需开启两步验证，使用应用专用密码 |

### 测试连接

填完信息后点击**测试连接**，系统会尝试登录邮箱，成功后显示绿色提示。

### 启动邮件监控

配置成功后，点击**启动邮件轮询**。之后系统会定期检查新邮件，有新附件时自动处理。你可以在**设置** → **邮件**页面查看上次同步时间和状态。

## 7. 自我清醒机制

### 什么是"自我清醒"

你有没有遇到过这种情况：和 AI 聊学习，每次都要从头解释"我是谁、学什么、目前进度如何"？PersonalAC 的"自我清醒"机制就是为了解决这个问题。

每次对话开始前，AI 会先在内部查阅一份**实时快照**，了解：

- 距离目标考试还有多少天
- 有哪些知识点按遗忘曲线计算已经到了复习时间
- 上次对话中有没有没解决的问题
- 最近学习活动的概况

这一切对你来说是透明的——你只需要开始说话，AI 已经准备好了。

### 开场白会反映当前状态

AI 的第一条消息不是通用问候，而是根据当前状态生成的个性化内容。例如距离考试越近、有更多待复习内容，AI 的开场会越来越有紧迫感。

### 自动运行，不需要配置

这个机制完全自动运行，大约每小时更新一次快照。你不需要做任何设置。

### 让 AI 更准确的方法

快照的准确性取决于系统中的数据量。你放入系统的信息越多，AI 的感知越准确：

- 上传试卷让 AI 分析
- 完成 AI 出的题目
- 告诉 AI 你学了什么，让它帮你记录

## 8. 学习追踪原理

### 遗忘曲线

人的记忆会随时间衰退，这是心理学家艾宾浩斯发现的规律（遗忘曲线）。PersonalAC 对每个知识点都会记录"记忆稳定性"，并估算你当前对这个知识点的记忆留存率。

当留存率下降到一定程度，AI 就会在自我清醒快照中把这个知识点标记为"该复习了"，并在对话中主动提醒你。

复习成功后，记忆稳定性会提升，下次到期时间也会自动推后。

### 置信度

每个知识点有一个"掌握度"（0 到 100）。不同来源的数据对掌握度的影响不同：

- **监护人上传的成绩数据**：最可信，直接更新
- **AI 出题后你当场答对**：可信，更新掌握度
- **你说"我会了"但没有验证**：AI 会先出题验证，答对才算数

这样设计是为了防止掌握度虚高，让数据尽量真实反映学习状态。

### 前置知识推断

如果某个知识点反复答错，AI 会尝试推断是不是因为前置知识没掌握好。比如高中数学中导数应用反复出错，AI 可能会回溯检查函数基础概念的掌握情况，从根本上找到薄弱原因。

### 讲解方法记录

AI 会记录对每个知识点用过的讲解方式。如果某种解释方法你没有理解，AI 下次会换一种方式讲，而不是重复失败的方法。

## 9. 常见问题

**Q：AI 没有记住上次对话的内容，每次都像第一次认识我？**

对话本身的记忆是有限的，但"学习记录"是持久的。区别在于：AI 是否调用了工具把内容写入数据库。

如果你学了一个知识点，直接告诉 AI "帮我把刚才学的内容记录一下"，AI 会调用工具保存，下次就能看到了。光聊天不会自动保存。

---

**Q：我想切换学生账户怎么办？**

点击右上角头像，选择**退出登录**，然后用另一个学生的 Sync Token 重新登录即可。

---

**Q：忘记了 Sync Token 怎么办？**

有两个地方可以找到：

1. 进入**设置** → **账户**选项卡，Token 会显示在页面上
2. 本地版：在终端运行 `personalac token`，会直接输出当前 Token
3. 服务器版：查看服务器启动时的终端输出，Token 会在每次启动时打印出来

---

**Q：Sync Token 是密码吗？安全吗？**

Sync Token 相当于登录密码。持有这个 Token 的人可以登录对应账户，所以请不要把它发到公开的地方。Token 以加密方式存储在数据库中。

如果你怀疑 Token 泄露，可以在**设置** → **账户**中重置 Token，旧 Token 立即失效。

---

**Q：AI 一直在思考，回复非常慢怎么办？**

如果使用的是 o1、o3、claude-thinking 等推理模型，它们本身就比较慢，属于正常现象。如果觉得太慢，可以在设置中换成更快的模型，比如 claude-3-5-haiku 或 gpt-4o-mini。

---

**Q：邮件配置测试失败？**

常见原因：

- 使用的是邮箱登录密码，而不是授权码。QQ 邮箱、163、Gmail 都需要在邮箱设置里单独生成授权码
- 邮箱没有开启 IMAP 服务（需要去邮箱设置中手动开启）
- Gmail 需要先开启"两步验证"，然后生成"应用专用密码"

---

**Q：想重置所有数据怎么办？**

删除数据库文件后重启即可，系统会从零开始。

- 本地版：删除 `~/.personalac/personalac.db`
- 服务器版：删除 `data/personalac.db`（路径以实际 `DATA_DIR` 配置为准）

注意：这会清空所有账户、知识点、对话记录，无法恢复，请谨慎操作。

---

**Q：可以在手机上用吗？**

可以。只要手机和运行 PersonalAC 的电脑在同一个 Wi-Fi 下，用手机浏览器访问电脑的局域网 IP 地址加端口号即可，例如 `http://192.168.1.x:3000`。界面已适配移动端。
